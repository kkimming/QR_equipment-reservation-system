# 2주차: UI/UX 화면 흐름도 및 와이어프레임 명세

## 1. 액션 플로우 (User Journey)
- [사용자] 메인 화면 접속 -> QR 스캔 버튼 클릭 -> 카메라 권한 승인 -> QR 인식 -> 기자재 정보 확인 -> 대여 승인 완료

## 2. 트러블슈팅 (Mobile-First 뷰포트 대응)
- **문제**: 데스크톱 기준 뷰포트만 고려하여 레이아웃을 구성하여 모바일 기기에서 접속 시 카메라 스캔 영역의 비율이 깨지고 화면 밖으로 밀려나는 현상 발생.
- **해결**: Mobile-First 디자인 원칙을 적용하여 CSS 상대 단위(`vh`, `vw`) 및 Flexbox 구조를 수정하고, **카메라 프리뷰 영역을 1:1 비율**로 고정하여 모바일 브라우저 주소창 영역에서도 레이아웃이 깨지지 않도록 재설계함.
